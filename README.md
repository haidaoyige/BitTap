# BitTap｜用一张 NFC 卡，保管自己的 BTC

**简体中文** · [English](README.en.md)

BitTap 是一款开源的 Android NFC 冷钱包工具。它在手机上离线生成 BTC 私钥，用你设置的密码加密，再保存到 NFC 卡片和独立备份文件中。

日常收款时，贴卡查看收款地址；需要转出时，输入密码恢复私钥，导入兼容钱包完成转账。无需注册账号，也无需将私钥交给第三方。

## 为什么选择 NFC 保存钱包？

**成本低，方便做副本**

使用价格低廉的 NTAG215/216 NFC 卡片，同一个钱包可以保存到多张卡片，分别保管，减少对单一载体的依赖。

**不用充电，贴卡即可读取**

无源卡片没有电池，卡片寿命长达 10 年之久，防潮防蛀。使用支持 NFC 的兼容 Android 手机即可读取，不需要 USB 接头或专用读卡器。

**外形普通，便于隐蔽保管**

NFC 卡片可通过贴纸或印刷定制成普通名片等外观，与日常卡片一同收纳，减少引人注意的机会。

**卡片与密码分开保管**

卡片保存的是加密私钥，密码不会写入卡片。相比直接记录明文私钥，拿到卡片的人仍需破解密码才能恢复私钥，增加安全冗余。

**让卡片只承担存储工作**

私钥在手机上生成和加密，NFC 卡不负责生成钱包私钥，也不签名交易。这减少了对卡片执行复杂钱包逻辑的依赖。

使用 NFC 作为冷钱包的价值，在于外形普通、数据可加密和低成本备份。它不能替代钢板的抗灾能力，也不代表比其他存储介质更安全，只是为您的 BTC 自托管多提供一种选择。

## 当前版本可以做什么？

- 离线生成 BTC 私钥，可选相机数据作为补充随机输入。
- 使用密码加密钱包，写卡后自动读回核对，并要求保存加密文件备份。
- 同一钱包支持 SegWit、Legacy、P2SH、Taproot 四种收款地址。
- 建立本机核验记录后，再次读取相同数据可免密码核对公开地址，无需重新解密私钥。
- 展示收款二维码、复制地址、保存收款图片；按需恢复 WIF 私钥及私钥二维码。
- 支持同钱包多卡保存，以及兼容卡片的可选永久只读。
- 支持中文、英文、日文、韩文及跟随系统语言。

当前版本 **0.7.0 / 内部版本 50**，支持 **Android 12 及以上、BTC 主网**。BitTap 不托管资金，不签名或广播交易，也不内置查询余额。

密码丢失无法重置。请将密码与卡片、备份分开保管，并先用无资金钱包验证制作和恢复流程。当前版本仍处于实验阶段，开源、离线和测试都不构成资金安全保证。
