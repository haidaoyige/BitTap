# 0.7.0

内部版本50，Android12起支持；仓库改为公开，许可保持Apache-2.0。整合本机免密码地址核验记录、Keystore私钥会话、辅助功能门禁、scrypt p=3与BIP38边界修订、NFC有界后台处理和NTAG215/216专用锁位修复。移除随机密码并调整首页和制作页布局。旧p=1测试备份不兼容，实体NFC仍需验收。完整范围见[发布说明](release/v0.7.0/RELEASE-NOTES.md)。

# 0.5.0

正式编号 V0.5.0，内部版本 15；以 BitTap 建立独立私有仓库，沿用原应用 ID 和发行签名以支持覆盖更新。

- 汇总已确认的 BitTap 原型、四语言、每次入口风险确认、钱包备注、相机增强和 NFC 可选永久只读。
- 完整地址展示、多地址切换、收款地址和私钥二维码的多语言图片导出；底部英文标语固定。
- 私钥复制确认及剪贴板结果核验，恢复页按钮和对齐优化；输入时键盘避让。
- 保留写后读回、必须保存加密备份、多卡同钱包和会话清理规则。

此版本号不代表独立安全审计或实体 NFC 验收已完成；详见发布验证记录和历史安全评审。

# 0.4.0

内部版本 14：私钥二维码入口复用展示地址图标；恢复页的“如何转出 BTC”右侧与上方展示地址对齐；“隐藏私钥，返回首页”改为橙色按钮。Android 11 及以上统一处理系统栏 / 键盘 Insets，所有输入框在获取焦点、键盘变化或窗口缩放后保持可见；旧系统继续使用 adjustResize。

内部版本 13：移除恢复页面底部的“复制 WIF 私钥”按钮，保留私钥二维码弹窗内的复制入口。复制先弹出已确认的四语言风险确认；取消或关闭不写入剪贴板，切后台 / 返回首页 / 关闭二维码同时撤销确认。只有本次确认且实际读回一致才报告复制成功，失败时保留弹窗及错误提示。

内部版本 12：WIF 私钥 PNG 采用已确认的“风险提示优先”设计，包含 Logo、明文风险提示、WIF 二维码和文本、尽快转移全部 BTC 与停止使用旧地址的提示。中文 / 英文 / 日文 / 韩文随 App 语言，底部 `YOUR KEYS. YOUR BITCOIN.` 固定英文。保留显式保存确认、系统文件选择器及内存导出清理，不再显示“这不是加密备份”文案。

内部版本 11：收款图片底部标语固定为 “YOUR KEYS. YOUR BITCOIN.”，不随 App 或系统语言变化；标题、网络名称和地址标签仍随 App 语言显示。

内部版本 10：收款地址导出 PNG 采用已确认的暖白极简设计，包含 BitTap Logo、二维码、完整地址及地址类型。导出文字跟随 App 当前中文 / 英文 / 日文 / 韩文及跟随系统语言设置；地址自动换行，不截断。保持只通过系统文件选择器显式保存，二维码只编码公开地址。

内部版本 9：首页操作按钮的图标与文字垂直居中；卡面两行英文各放大一号。

内部版本 8 对齐已确认原型：恢复顶栏语言胶囊与选择器选中态、关于弹窗、九组安全原理折叠及返回关于路径、完整制作表单分组与备注计数、独立相机照片确认、写卡 / 解密与全部帮助弹层样式。修复顶栏裁边和原生开关滑块裁切。密钥生成、加密格式、地址推导与强制文件备份规则保持；相机新增的照片预览仅在内存，使用后及退出时清理。

内部版本 7（BitTap 原型实现）：统一品牌和横排卡片插画；首页四语言与跟随系统；每次入口免责声明及离线完整条款；CG3 公开且认证的钱包备注；可选 Camera2 混合随机源；NFC 卡型帮助；默认关闭、二次确认的 NTAG215/216 永久只读和独立结果状态；新版 WIF / 安全原理帮助；经隐私确认后在外部浏览器查询公开地址。恢复 CLI 与独立 Python 验证支持 CG3，旧格式继续兼容。实体相机和 NFC 锁定需要真机验收。

内部版本 6 将地址操作统一为“展示地址”，二维码使用与 NFC 一致的底部卡片；完整地址居中换行，显示名称改为 SegWit 和 P2SH。收款地址与私钥二维码支持通过系统文件选择器保存 PNG，私钥图片先确认明文风险，写入关闭且读回一致后才提示保存成功；临时 PNG 仅存内存并按取消、超时与生命周期清理。取消加密文本复制、粘贴入口，保留 NFC 和文件导入。剪贴板以唯一标签和内容读回确认复制结果，拒绝或不可核实时不再报成功。

更名 BitNFC，按已确认原型实现 BTC 橙色分步制作 / 读取流程。采用原始 Bitcoin SVG 字形和 NFC 弧线矢量标识。地址栏内展开其他收款地址，移除压缩公钥和密文详情展示，恢复帮助改为三条 WIF 转出说明。

内部版本 5 补回原型中的 NFC 贴卡底部弹层：检查、读取、写入均显示卡片插画与感应动画；实际硬件回调更新状态，等待时可取消，处理中禁止取消，切后台关闭。保留原有容量、同卡、覆盖确认和写后读回核验，沿用发行签名以覆盖更新。

“复制地址”旁新增收款地址二维码入口，覆盖制作、完成、解密前后及四种地址列表。弹窗展示完整主网地址和地址类型，核对通过时显示“已与私钥核对，地址正确”，解密前保留“待解密核验”。地址二维码仅编码该公开地址，生成前校验网络与地址校验和；关闭或切到后台清理二维码位图。

新 CG2 格式公开存储并认证四种地址，解密后由私钥逐项重算核对；旧 CG1 和 BIP38 读取仍兼容，离线恢复 CLI 同步支持 CG2。写卡继续检查容量、可写状态、原内容和同一 UID，写入后实时读回核对。

文件备份必须在成功关闭并读回一致后，才算保存完成。取消、失败或复制文本不能跳过备份。新增将完全相同的加密钱包写入另一张 NFC 卡的流程，保留原地址和密码。密码强度提示只作建议，不增加弱密码门槛。密文及公开流程状态仅在配置变化时通过内存承接，不写入系统页面恢复状态；后台清除密码和明文私钥，返回首页统一清理会话、输入、二维码、候选卡数据及仍属于本 App 的剪贴板。

# 0.3.0

完成用户提出的 6 项修改：每张卡一把私钥同时展示四种主网地址与小字说明；输入框右侧睁眼/闭眼密码图标；“准备制作NFC冷钱包”移到防盗加密私钥下方；每个收款地址右侧复制图标与成功提示；加密备份复制/保存说明弹窗；“再次制作NFC冷钱包”保存确认与完整状态重置。

CG1 和 NFC 存储格式保持不变，恢复工具新增四种地址输出。Taproot 使用 BIP341 key-only tweak 和 Bech32m，提供具体的单私钥恢复兼容提示；不宣称通用 WIF 导入支持 Taproot。未新增联网或链上转账功能。
