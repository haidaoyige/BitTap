# Design references

`bittap-next-prototype.html` is the approved BitTap prototype for this iteration: four languages, camera supplement, public note, disclaimer, supported cards and permanent read-only. See [implementation and validation limits](../BITTAP-IMPLEMENTATION.en.md) for internal build7. Prototypes contain demo data; design-stage statements such as “not implemented yet” do not establish current build status. Implementation notes and validation reports take precedence.

`bitnfc-v040-prototype.html` is the approved 0.4.0 interaction prototype. Its placeholder data cannot generate or recover real keys. Actual behavior is defined by the root README and docs/FORMAT.md.

`logo/` retains the original Bitcoin SVG, composite marks and source-path hashes. Android ic_launcher/ic_brand_white reuse the Bitcoin path verbatim, applying only uniform scale/translation and added NFC arcs.

`original-prototype.html` is an early historical page, not current behavior.

The revised QR dialogs and entry points were approved and included in build6; see [implementation and checks](qr-dialog-proposal.en.md).
