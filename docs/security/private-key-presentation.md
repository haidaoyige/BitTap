# BTA-04：私钥展示与辅助功能数据

2026-10-18，0.6.0 code28 本地测试包修改。该实现处理主动查看 WIF 后的普通文本读取出口，不承诺抵御已被攻破的系统。

## 展示实现

- 仅将私钥文本区域替换为 `PrivateKeyView`。它直接绘制 `StaticLayout`，真实 WIF 不再赋给界面上的 `TextView`、内容描述、提示文字或辅助功能节点。
- 使用一个不接收任何私钥、也不附加到窗口的空 `TextView` 获取原主题字号、字体、行高及绘制参数，使新旧效果一致。私钥字符由控件自持的 `char[]` 提供。
- 控件只向读屏提供本地化的“敏感私钥内容”说明。复制、保存、如何转出 BTC、取消和关闭等按钮保留原样；正常说明仍可读屏，私钥字符不朗读。
- 禁止私钥视图保存状态及自动填充；Android 11+ 排除内容捕获；Android 14+ 对私钥绘制区域与私钥二维码加敏感辅助功能数据标志。
- 原有 `FLAG_SECURE`、遮挡点击保护、60 秒空闲／120 秒绝对期限、退出及后台清理继续适用。关闭、分离视图或会话清理时，覆盖控件持有的字符数组并释放文字排版。

## 验证

- Android 9/API28 与 Android 15/API35：四种语言、三种宽度及两档字体缩放，绘制像素与旧文本控件一致；四种语言下完整私钥弹窗也逐像素相同。
- 在独立测试 APK 中启用测试辅助功能服务，显式请求非重要视图与窗口内容，并声明为辅助功能工具。它可以读取普通界面，未从新私钥视图及相关事件读到测试 WIF。
- 正对照把同一公开测试 WIF 放回原普通文本控件，测试服务可以读到，证明检查并非由服务未连接、窗口不可见或 `FLAG_SECURE` 造成假阴性。
- 测试覆盖原复制确认、保存确认、重开弹窗与后台清理；设备专项 API35 85 项、API28 72 项通过。测试服务、桥接 Provider、测试 Runner 和公开私钥向量不进入交付主 APK。

## 保护边界

- `importantForAccessibility` 不是安全边界；本方案不依靠把普通文本控件标为“不重要”来隐藏 WIF。
- Android 的敏感辅助功能标志有系统版本及服务类别边界；专用绘制区域本身不提供 WIF 文本，是额外保护的基础。
- 恶意且已授权的辅助功能仍可能自动操作按钮；用户明确复制或导出后的明文也有相应风险。本修改不通过禁止全部辅助功能来改变现有产品流程。
- 私钥解密后仍存在进程内存中。覆盖自持字符数组并不等于能保证回收所有系统、字体引擎、字符串或渲染副本，Root、注入及失陷系统不在该措施的防护保证内。
- 本地测试结果不能代替独立审计方复审，也不能代表所有 ROM 或所有辅助功能组合均已验收。
