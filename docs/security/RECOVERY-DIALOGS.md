# code18 读取与恢复页面

本轮落实已确认的紧凑双页排版及两个底部弹窗；不改变密码学格式、地址推导、密码强度策略或导出确认文案。

- 读取页没有密码输入框，点击“解锁冷钱包”才创建密码弹窗。“换一张卡片 / 备份”为次级按钮，打开 NFC／文件来源选择，取消不丢弃已读取数据。
- 恢复页只有“查看私钥”和“隐藏私钥，返回首页”两个主要操作，没有内联 WIF、显示开关或转移帮助入口。
- “查看私钥”显示真实可扫描二维码及其下的完整 WIF 文本；复制保留原确认、写入读回核对与系统版本限制，保存保留明文图片确认。转移帮助位于该弹窗内。
- 钱包备注仅标为“公开可见”；主地址和其他四地址列表逐项使用“待核验 / 已核验”。“已核验”仅指本次解密推导结果与卡片/备份地址一致，不是余额或来源身份认证。
- 密码弹窗关闭时清空输入，移除 AppUi 输入列表和点击/编辑回调中的对应视图引用。空密码不开始解密，错误密码回到空的重试弹窗，已关闭的旧按钮不能启动解密。
- 旧备份解密允许原短密码；新建钱包的十字符下限不用于阻止旧备份恢复。
- 私钥弹窗关闭或进入转移帮助时覆盖 WIF TextView，解除活动字段引用，擦除并回收二维码位图。后台和返回首页沿用已有私钥缓冲区关闭与会话清理。
- 主页面及弹窗保留安全窗口和遮挡触摸保护；私钥文本不参与视图保存或自动填充。密码框使用系统安全输入及不学习标记，并随键盘调整弹窗。

这是缩小展示范围与控制视图生命周期的修改。查看弹窗仍在进程中包含明文 WIF，具有权限的恶意服务或被攻破的系统仍可能读取；不宣称解决所有辅助功能读取风险，也不能保证 JVM 历史字符串的取证级擦除。前台两分钟/空闲六十秒锁定仍是独立原型，未在本轮实施；原有私钥二维码六十秒关闭逻辑保留。

设备检查使用公开标量 1 夹具，覆盖四语言、错误/空密码、键盘、取消/重开、二维码与 WIF 一致、帮助往返、弹窗关闭、后台和回首页。发行签名测试包验证结果保存在工作区外层 `BitTap-security-validation/device-test-code18/`；不把模拟器检查当作实体 NFC 或无漏洞证明。
