# BTA-04：恢复会话封装与敏感操作门禁（code40）

2026-10-20。本次在 code39 基础上加固 BTA-04，不修改卡片/备份格式、地址推导、密码 KDF 或正常页面排版。历史 code28 的私钥绘制保护仍保留，但其“允许所有辅助功能操作”的策略被本次替代。

## 会话中的私钥

- 密码解密、地址重新推导和一致性校验在后台线程完成。随后将 32 字节私钥立即用 Android Keystore 内不可导出的 AES-256-GCM 密钥封装，关闭并覆盖原 `WalletCrypto.Unlocked` 自持标量。
- Activity 的恢复会话仅持有公开地址/备注、12 字节 nonce、48 字节认证密文和随机密钥别名；不持有原解密对象、密码或长期明文 WIF。会话认证数据绑定公开地址及备注，篡改封装数据会使会话失效。
- 仅点击“查看私钥”时在后台临时解封，清理自持原始标量，再向受保护绘制控件提供短期字符。查看弹窗关闭时清理文字、二维码及排版。复制和图片导出使用当前查看弹窗的内容，不额外保留另一份解封会话。
- 返回首页、进入后台、空闲 60 秒或解锁满 120 秒时，关闭会话并覆盖自持密文/nonce；异步删除 Keystore 会话别名，避免阻塞主线程。异常退出或删除失败留下的别名，在下次进程首次建会话前清理。会话密文不落盘、不进 Bundle、Preferences、日志或应用缓存；仅残留别名不能恢复已丢失的会话密文。
- Keystore 不可用或认证失败时停止操作，不回退成应用自持明文密钥或软件 AES 包装密钥。硬件支持因设备而异，未承诺所有手机均使用 TEE/StrongBox。

## 辅助功能服务门禁

- 只要系统配置或启用了任何辅助功能服务，即拦截新建密码、恢复密码、查看/复制私钥和私钥图片导出。没有包名白名单，也没有生产测试绕过；包括 TalkBack 等合法服务，属于本次明确接受的可访问性取舍。
- 普通公开地址仍可读取与展示。关闭服务不会自动恢复已取消操作或自动解锁，用户必须重新点击并输入密码。
- 观察系统服务设置及启停状态；每个敏感入口与异步结果提交点再次检查。处理中启用服务会使旧回调、旧确认按钮失效，清理密码/私钥/二维码/待导出私钥图片并关闭会话。
- 私钥图片文件任务在提供方读写前后再次检查服务状态及原期限；门禁变化取消应用持有的任务和数据。不能撤回外部提供方已经收到的字节，也不能保证强制结束不合作的提供方底层调用。
- 提示采用现有 BitTap 底部弹窗样式，并提供中、英、日、韩四种语言。其余正常交互不增加重复输入密码步骤。

## 验证范围

本次增加核心封装/关闭测试、真实 Android Keystore 不可导出/解封/篡改失败/清理测试，以及独立进程辅助功能服务的正对照与门禁测试。原有密码、地址、复制确认、私钥图片、超时、文件故障和四语言 UI 回归继续运行；最终结果以交付验证记录为准。

测试只使用公开无资金的标量 1 等测试向量；测试服务、Provider 与公开私钥不进入主 APK。模拟器测试不代表全部 OEM、真实 NFC 标签与外部钱包资金路径验收，也不等于原审计方复审签字。

## 仍然存在的边界

解密、推导地址或明确查看/导出时仍必须在进程中短暂处理私钥。Java String、BigInteger、密码学提供方、输入法和渲染系统可能产生无法可靠覆盖的副本。Root、进程注入、已被攻破的系统或恶意高权限组件仍可能截取使用中的秘密，或借受控应用调用 Keystore；本次不宣称“私钥从不进内存”或“所有内存均已物理擦除”。

用户明确复制/保存的 WIF 与私钥图片属于明文导出；自动锁定不能删除其他应用、外部文件提供方、剪贴板历史或备份同步已取得的副本。

BTA-02 的未核验公开地址流程未在本次修改。BTA-08 的个人私有仓库保护计划限制及临时保留的审计协作者写权限、BTA-11 邮箱收信实测等事项亦不能因本次修改而记为闭环。
