## 尚未接入的 3 项主要 App 工作

1. **私钥自动锁定**：最长解锁 2 分钟，或空闲 60 秒，以较早者为准；先清理本次私钥及临时出口，再回到密码页并提示。原 WIF 复制确认文案保持。
2. **仅核验地址的独立路径**：输入密码短暂解密和核对四类地址后，立即清理私钥；需要转出时另行解锁。此路径仍会短暂在内存中处理私钥，不称为私钥从未进入内存。
3. **私钥显示的辅助功能语义防护**：限制秘密被普通可访问性文本直接读取，同时保留按钮、状态和正常读屏导航；需要单独确认与验收。

其中仅核验地址的独立路径、辅助功能处理细节属于此前的待确认方案。本轮盘点不代替用户批准，不自动开始实施。

随机长密码按钮仍为可选提案，未确认实施，不计入上述 3 项主要 App 工作。
