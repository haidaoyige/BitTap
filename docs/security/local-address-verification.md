# 本机公开地址核验记录

## 信任建立与后续读取

- 制作流程使用生成后恢复校验得到的四种地址，NFC 写入、读回比对及必需的加密备份保存均成功后建立记录。
- 恢复流程第一次输入完整密码，解密并从私钥重新推导、核对四种地址后建立记录。
- 后续读取对严格解析后的完整钱包负载计算带版本域分隔的 SHA-256，使用全部 32 字节比对已认证记录。随机参数、地址、备注和密文的任何变动均不能继承原核验结果。此比对不执行钱包密码派生或私钥解密。
- 核验状态只适用于对应收款地址，不能证明卡片物理身份、余额或链上状态。

## 存储与边界

记录只含钱包负载摘要、四种公开地址、公开备注、创建时间及可选 NFC UID 提示。不存储密码、密码校验值、私钥、钱包解密密钥或完整加密备份。文件由独立且不可导出的 Android Keystore AES-256-GCM 密钥认证加密，原子写入 noBackupFilesDir；应用禁用云备份和设备迁移。

UID 只用于识别“曾关联此卡片但数据不同”，不是信任依据。同一完整负载写在另一张卡上仍可匹配。新手机或未知 UID 的未知负载只能标为待核验。已知 UID 数据变化时，需重新输入密码并确认前后公开信息后保存新记录，不覆盖旧记录。旧的完整有效负载仍可能匹配历史记录，本功能不提供防回滚或防克隆保证。

记录损坏、密钥不可用或读取失败时不能免密核验。新近密码核验仍可在当前会话使用；记录保存失败会提示下次仍需密码。卸载应用或清除数据后须重新建立记录。删除核验记录不影响 NFC 卡或用户备份文件。返回首页仅清理会话，已保存的公开核验记录保留。

## 私钥边界

第一次密码核验会短暂处理明文私钥，之后立即封装为独立 Keystore 会话密文；只有明确查看、复制或保存私钥时才再次短暂解封。同一有效会话不重复输入密码。空闲 60 秒或解锁总计 120 秒（先到者），以及切后台或返回首页，会清除私钥会话与展示。自动锁定后公开地址核验结果可以保留。

本机制减少重复输入密码和解密私钥的次数，不能保证已被 root、恶意高权限服务或进程注入攻破的设备安全，也不能保证 Java、系统或用户导出的明文副本可被不可恢复地擦除。
