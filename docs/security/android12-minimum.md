# Android 12 最低支持版本（code41）

当前开发版 0.6.2 / code41 的 `minSdk` 为 31，即 Android 12 及之后版本；`targetSdk` 和 `compileSdk` 仍为 35。Android 9～11 不能安装此新版本。旧的发布附件及其历史验证记录保持原样，不表示旧 APK 自动获得本次修改。

## 精简范围

- 删除仅用于 Android 9 的 WIF 剪贴板禁用策略、四语言提示及旧平台测试分支。
- Activity 和所有受保护弹窗统一设置 `FLAG_SECURE`、`setHideOverlayWindows(true)`；完整与局部遮挡检测无旧系统降级路径。
- 页面和密码弹窗统一使用现代系统栏 / IME Insets；私钥展示统一禁止内容捕获，触感反馈使用现代接口。
- 删除低版本 API 内联兼容注释和不再需要的 Lint 抑制。
- 保留 Android 13 返回手势、Android 14 敏感辅助功能内容标记的版本判断。

不调整 UI 排版、文案或正常操作流程；不改动随机源、地址推导、钱包格式、scrypt / AES-GCM、NFC 写入或会话时限。私钥导出确认、剪贴板校验与清理、辅助功能保护和自动锁定全部保留。

## 安全边界

提高最低版本统一了平台基础能力，不能关闭 BTA-02、已复制私钥的剪贴板残留、弱密码强度误判及未备份先收款的风险；也不证明 Android 12 设备仍有安全补丁或可信硬件。

## 测试说明

设备测试只使用公开测试向量与未入金的临时钱包。自动化明确保持测试模拟器唤醒，避免息屏导致前台剪贴板权限变化；这不是生产 App 的设置。

空闲测试按照二维码准备完成后的真实剩余期限衡量等待时间，不重置或加速会话时钟。剪贴板断言等待窗口获得焦点后才读回完整测试值，不能把读取被拒绝或 null 当成保护通过。

## 本轮验证结果（2026-10-21）

- Debug / unsigned Release 与测试 APK 构建成功；102 项单元测试全部通过。Release Lint 无 error / fatal，9 个 warning。
- APK `minSdkVersion=31`、`targetSdkVersion=35`。Android 9 模拟器实际安装被 `INSTALL_FAILED_OLDER_SDK` 拒绝。
- Android 15：创建 673 项、恢复 296 项、复制确认 80 项、防遮挡 137 项、键盘 88 项断言通过。这些不是独立漏洞数量。
- Android 12 复测：创建 673 项、恢复 300 项、复制确认 80 项、防遮挡 137 项、键盘 88 项、会话期限 / 文件操作 64 项、实际辅助功能 / 私钥像素等价性 109 项全部通过；各专项断言有重叠，不能相加作为独立安全保证。
- 环境复查：单台模拟器冷启动，使用 3072 MB 内存、4 核及当前软件渲染配置。先完成一分钟桌面 / 设置焦点切换观察，再执行应用回归；全过程 SystemUI 进程稳定，测试后崩溃缓冲为空，`lastanr` 报告本次启动以来无 ANR。此前失败记录保留，不覆盖成成功。
- 真实等待 60 秒空闲锁定通过；120 秒绝对期限采用边界状态测试，不将其描述为真实等待 120 秒。原有文件测试提供方的取消、超时和迟到结果检查本次通过。
- Android 12 在密码 IME 出现时可能拒绝全屏自动化截图。测试截图新增应用视图渲染备用路径，并为每张截图写入采集模式；该路径不包含系统 IME，不冒充整屏截图。键盘避让和输入框可见性仍通过实际 WindowInsets、屏幕坐标和可见矩形断言。
- 本次复测只调整测试截图工具与验证记录，未进一步修改生产 UI 或安全逻辑。102 项单元测试为前一轮结果；本轮重跑的是上述七项 Android 12 设备专项。
- 实体 NFC、OEM 差异及真实手机仍需实机验收；模拟器通过不构成资金安全认证。

本轮未签发新的发布 APK，也未向 GitHub 推送或发布。审计中既有的风险没有因提高最低系统版本而关闭。
