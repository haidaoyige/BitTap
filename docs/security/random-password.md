# 历史功能记录：本机随机强密码

2026-10-20：根据实机使用反馈，后续开发版本（code32）已移除此功能，包括随机生成、复制密码、重新生成与保存确认。用户手动输入并确认密码。以下仅记录已发布 v0.6.2/code31 的历史实现与测试，不描述当前开发版本。


制作钱包的密码弹窗允许用户主动生成 32 位随机密码。每一位均由平台 `SecureRandom.nextInt(94)` 从可见 ASCII U+0021–U+007E 均匀采样；若整串未满足英文大小写、数字、半角标点四类要求，就重新采样整串。最多尝试 128 次，随机源异常时停止，不使用时间、设备信息、伪随机回退或固定格式补位。

生成函数返回由调用者拥有的 `char[]`，填入 EditText 后立即清零。密码不会写入偏好、日志、卡片或普通文件，不增加云端保存或找回功能。显式复制会将明文交给系统剪贴板，其字符串及系统副本不属于可承诺全部擦除的范围。

## 交互

- 随机生成后，首个密码框显示完整值，使用等宽字体、软换行、关闭横向滚动和省略。视觉换行不向密码中添加换行字符。再次输入框保持为空。
- 生成状态显示复制入口、丢失风险说明及“已安全保存”勾选。确认输入一致并勾选保存后才能生成钱包；实际生成入口再次校验，不能只靠灰色按钮。
- 修改首个输入会退出随机生成状态并撤销保存勾选。重新生成前有替换确认，再生成会清空旧确认输入和保存勾选，并尝试清除本工具复制的旧密码。
- 弹窗取消、后台和生成钱包时沿用输入清理；不持久化随机密码或保存勾选。切到其他 App 保存密码会关闭当前密码弹窗，回来后需从已保存的位置重新录入。
- 四种语言同步，说明、标签、按钮和保存勾选均允许换行。只修改制作流程，不改变解锁私钥和钱包备份格式。

## 复制

复制前确认当前弹窗、当前输入、前台和非处理状态；剪贴板设置敏感标记，并核对写入后的标签与完整内容，未确认则明确报错，不提示成功。

沿用敏感剪贴板策略：Android 9 禁止复制并提示手动记录；Android 10+ 可复制。自有剪贴板在 120 秒后尝试清除，后台系统限制时在恢复前台后重试；取消、重新生成和完成时也尝试清理。只处理本工具拥有的标记，不清除其他 App 后来写入的内容。不承诺能清除外部 App、输入法或系统保留的历史副本。

## 验证

核心随机生成测试覆盖采样范围、缺少字符类别后的整串重试、随机源错误和卡住时停止、生产采样及缓冲清理调用。Android 设备回归覆盖四语言的显示、正常与放大字体下完整软换行、复制读回与敏感标记、粘贴确认、保存门槛、重新生成/保留、撤销和陈旧点击，以及使用实际生成的密码加密和恢复一次性无资金钱包。测试不保存生成密码或随机测试私钥。

2026-10-19 本地结果：核心、App、恢复工具共 99 项单元测试通过（0 失败/错误/跳过），Debug App 和 instrumentation 包构建通过；lint 0 error、9 项既有 warning。专用 API35 模拟器 385 项、API28 模拟器 377 项制作流程断言通过；后者实际覆盖禁止复制随机密码及手动确认。两者都覆盖四语言、16/24sp 下密码布局不省略并包含完整 32 字符。英文原生截图仅使用公开固定测试口令，未保存实际随机生成的密码画面。证据位于仓库外 `BitTap-security-validation/random-password/`。这些检查不构成密码熵认证或资金安全保证。
