# BitTap v0.7.0 安全复审结果（公开版）

更新：2026-10-23。审计对象：**v0.7.0 / code50**，精确提交 [`53c281b5f3ba8fa47ac1c59e9166300b384aaf33`](https://github.com/haidaoyige/BitTap/tree/53c281b5f3ba8fa47ac1c59e9166300b384aaf33)。后续提交不自动继承此结论。

本报告由 Codex 辅助完成源码审查、主机验证、正式分发物核对及 Xiaomi Android15 软件真机检查。它不是第三方安全机构认证，也不保证绝对安全或真实资金安全。

## 最终状态

- **非设备审计、软件真机检查已完成。**137项单元测试、10项发布工具测试通过；实际相机生成、SAF备份、独立解密/四地址核对、重新导入和核验记录进程重启持久化通过。
- Keystore会话、辅助功能门禁、文件故障处理及真实60秒空闲/120.089秒绝对期限在指定设备覆盖范围内通过；各专项断言存在重叠，不相加作独立安全测试总数。
- 正式APK90个非签名条目与同提交独立CI一致，恢复ZIP与CI字节一致；本机恢复ZIP存在所用JDK不同下的编译差异，不声称本机全部字节重现。
- **实体卡总体验收未完成，后续已由用户停止。**普通写入/读回及首次失败后的重写曾通过；主动移卡后App正确报错，但后续读到不同类型对象，原卡最终内容未核实。**永久锁定未执行，不能标为已验收。**
- 仍保留格式合格弱密码、旧p=1备份恢复兼容、仓库保护细则和安全邮箱投递等边界。v0.6.1正式库产生的p=1备份不能由v0.7.0恢复，旧工具仍可恢复本次公开测试负载；不等于旧数据已损坏。
