## 新机制专项判断

### 本机公开地址核验记录

`WalletFingerprint` 对合法、规范化格式的**全部原文负载**做域分离和长度前缀 SHA-256，而非仅地址或卡 UID。测试逐字节修改得到不匹配或解析拒绝；实际分发库篡改密文也触发 GCM 拒绝。

`VerificationStore` 仅保存摘要、公开地址、备注、时间及卡片提示；使用 AES-GCM 和独立 Keystore alias，位于 noBackupFilesDir。原子写入、256 条/256 KiB 上限、解析校验、缺键/坏密文失败关闭。清除和保存受锁串行化。记录不证明卡片物理身份、余额或新鲜性；合法旧记录/旧卡内容的回滚不在保证范围。Android 实际落盘、删键、进程重启与跨版本升级的行为仍需设备补验。

### 私钥会话及出口

恢复后 `PrivateSession.seal` 在 finally 关闭原私钥 holder；会话只保存密文、随机 nonce 和公开数据，使用 AES-GCM AAD 绑定相关公开字段。退出时清空密文并异步删除 alias，下次进程启动清理残留 alias。`setUserAuthenticationRequired(false)` 意味着这不是生物识别授权机制；不可导出属性不自动等于已验证硬件 TEE/StrongBox。

WIF 的 String/字符数组、二维码像素以及明确导出的 PNG/剪贴板仍有明文窗口；源码采取所有权和过期清理，但不能证明 JVM/系统所有副本均被物理清零。门禁回调与 worker 输出检查降低辅助功能切换风险，不能替代本版真实服务切换测试。

### NFC / 专用永久锁定

数据 worker、启停控制与关闭 worker 分离且有界。写入前检查可写性、同 UID 和此前内容，写后重新读回。超时/取消/迟到回调不应进入成功分支；已经发出的底层写操作无法事务回滚，失败须保留“未确认”。

NTAG215/216 检查型号及镜像/访问配置，按 CC、动态锁位、配置锁位、静态锁位顺序写入并逐步读回；动态页 RFUI 写零。最终需再次读完整负载、锁位和 NDEF 只读标志。NXP 手册说明 CFGLCK 在芯片电源循环后才生效，因此移开重贴及真实射频验证不可被模型测试取代。[NXP NTAG213/215/216 Rev 3.2](https://www.nxp.com/docs/en/data-sheet/NTAG213_215_216.pdf)

发布方记录曾在 Xiaomi/Android16 遇到 NFC-LOCK-L3-TIME 与 NFC-D；本次源码调整和模拟器记录**不证明该 OEM 故障已经解决**。永久锁定、故意移卡/掉电均未执行，后续需精确确认测试卡及不可逆影响。
