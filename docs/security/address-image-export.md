# 地址导出图的核验提示与透明圆角

2026-10-18，已包含在 0.6.0 code28 本地测试 APK 中，未发布新的 GitHub Release。

- 保存未核验地址仍先显示原风险确认；用户继续后，图片在二维码上方显示“此地址导出时尚未与私钥核对。请先在 BitTap 中解密核验，再转入 BTC。”不再增加重复状态标签。
- 提示支持中文、英文、日文、韩文，随 App 当前语言切换。图片上的 `YOUR KEYS. YOUR BITCOIN.` 固定英文。
- 图片使用当前二维码对应地址及其核验状态，不从钱包或备注的状态推断。原有二维码所有者、会话版本和像素对象检查继续阻止旧确认导出另一张二维码。
- 已核验地址的导出图保留原有内容；未核验图根据提示实际换行高度下移二维码、完整地址与页脚。
- 收款地址及 WIF 私钥图片均以 RGBA PNG 保存。圆角外透明，圆角内保持暖白背景，二维码保持黑白模块及四模块留白。PNG 文件扩展名、MIME 类型及写入后读回验证不变。
- 透明角不代表整张图片透明。相册或聊天软件可能使用自身背景显示透明区域，或在二次转码时合成背景。
- 导出图只描述导出当时的状态；图片可被他人编辑，提示不能防篡改，也不能代替对实际收款地址与私钥的认证。

验证入口：`SmokeRunner -e imageOnly true`（图像、PNG、透明角、深浅背景扫码、四语言和四地址类型）、`-e addressSaveOnly true`（实际保存入口、核验状态传递、取消与旧确认失效）。全部测试仅使用公开标量测试向量，不使用真实钱包资料。

本次验证：API35 模拟器图像专项 419 项、保存入口专项 276 项通过；91 项单元测试通过，release lint 无错误（保留既有警告）。实际 PNG 为 1224 像素宽、8 位 RGBA，四角 alpha 为 0，编码后读回保持透明像素。该结论限于本次本地工作区构建，不代替独立安全复审或实际手机相册／聊天软件的二次处理验收。
