# BitTap 原型实现与后续对齐

内部版本 8 修正了内部版本 7 与原型不符的布局和导航，差异清单见 [UI 原型对齐报告](UI-PROTOTYPE-ALIGNMENT.md)。以下保留内部版本 7 的功能范围与历史验证记录。

本轮基于已确认的 BitTap 原型修改 Android 原生应用。版本名暂保持 0.4.0，内部版本从 6 升为 7，包名与原发行签名保持不变。本地候选包，尚未发布到 GitHub。

## 修改清单

1. **品牌与视觉**：BitTap 名称、BTC 橙色、横排平衡卡片；放大原 Bitcoin 字形与 NFC 标识，同时保留 `BITCOIN · OFFLINE`，下面增加 `YOUR KEYS. YOUR BITCOIN.`；感应圆环放在卡片后方。
2. **语言**：首页可选中文、英文、日文、韩文及跟随系统。仅持久化语言偏好，不保存钱包状态。完整免责声明四语言离线可读；安全原理长文沿用已确认的中文版本，其他语言明确提示该长文为中文。
3. **每次确认风险**：每次点击首页制作或读取，都重新弹出免责声明；不同意留在首页，完整条款返回后仍需同意才能继续。
4. **钱包备注**：制作页输入，公开写入 NFC / 加密备份；最多 16 个 Unicode 码点、64 字节，限制为文字、数字和允许的常规标点。解密前显示待核验，解密后由 GCM 认证。备注不是密码、密钥来源或文件名。旧格式显示无备注。
5. **可选相机增强**：Camera2 在本机采集 32 个不同预览帧摘要和最终照片摘要，与采集前取得的系统安全随机数通过 HMAC-SHA256 混合；拒绝采样得到合法私钥。系统随机源仍是基础。照片不保存，不调用外部相机。拒绝权限、失败、取消或切后台均清理；不能静默退回普通模式。
6. **帮助与余额入口**：支持卡片说明、完整安全原理、WIF 含义和 OKX / Electrum / BlueWallet 导入帮助；收款地址二维码提供外部浏览器查询入口，先提示网站会获知地址和网络信息。私钥二维码没有查询入口。
7. **永久只读**：默认关闭，主动开启后检查 NTAG215/216 支持情况；写入并读回一致后再单独确认不可撤销的硬件锁定。再次贴卡，核对完整 NDEF 与硬件锁位后才显示锁定成功；未锁定和状态未知分别显示。不是防复制或硬件防盗功能。
8. **兼容及清理**：新写入 CG3，备注与四地址共同受认证；兼容旧 CG2 / CG1 / 压缩 BIP38。Python 独立恢复与 Java 离线恢复工具同步支持 CG3。保留必须保存并读回加密文件、多卡同钱包、后台清明文、回首页清会话的规则。

## 数据保留的准确含义

生成、加密并恢复核验后，关闭明文私钥持有对象并清除自有字节缓冲。密文与公开地址在当前内存会话保留，以完成写卡、必须备份和同钱包多卡操作；不是写完第一张卡就删除密文。备份完成并返回首页后清理会话、输入、二维码、候选卡数据和仍属本应用的剪贴板。导出的备份文件或明文私钥图片由用户保管，不会自动删除。

Java、密码学提供程序、相机服务、键盘或系统可能持有应用无法控制的副本，因此不能承诺取证级彻底擦除或被入侵手机上的安全。

## 验证范围与待验项

候选 APK：`app/build/outputs/bittap/BitTap-0.4.0-code7-candidate.apk`。已通过 76 项单元测试、210 项模拟器交互断言、7 项 Camera2 模拟器链路断言，Release lint 无问题。沿用原发行签名，可覆盖原同签名发行包；仅 NFC 和 CAMERA 权限，无 INTERNET。APK 与离线恢复工具的哈希、逐项结果见 [本轮验证报告](release/bittap-code7/README.md)。

核心检查包括 CG3 备注认证、旧格式恢复、地址推导、相机混合固定向量、随机源失败停止、只读锁位判定、四语言入口、每次免责声明、文件备份、二维码和生命周期清理。模拟器测试 APK 与临时截图已移除，候选应用保留在首页。

**实体 NFC 和真实手机相机仍需验收**：NTAG215 / NTAG216 分别验证容量、覆盖、写后读回、默认不锁、主动永久锁定后跨设备无法覆盖、断开时的未知状态；真实相机验证权限拒绝、有效帧与最终照片匹配、后台中断、重新采集。模拟器中的卡片状态和相机摘要夹具不能代替这些硬件测试。

这是针对本轮变更的实现和回归，不是完整独立资金安全审计。历史安全评审中的风险和待办继续有效，不因改名或功能测试通过而关闭。
