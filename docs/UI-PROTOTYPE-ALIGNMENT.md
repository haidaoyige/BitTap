# BitTap 原型对齐修订 · 内部版本 8

基准为用户确认的 `docs/design/bittap-next-prototype.html`，选定「顶栏语言入口」「横排平衡」卡面。上一轮实现保留了主要功能，但多处使用普通文字或通用控件替代了原型的视觉分组和导航；本轮按原型逐项还原。

| 页面 / 交互 | 发现的差异 | 本轮修正 |
| --- | --- | --- |
| 首页顶栏 | 语言入口只有橙色文字；品牌字号、间距不同 | 胶囊边框、地球图标、当前语言及下拉箭头；统一品牌尺寸；修复负边距造成的图标裁边 |
| 首页 | 缺少离线图标与悬浮锁标识，卡片留白不同 | 补回图标、卡片阴影与悬浮锁；恢复标题、插画及按钮节奏 |
| 语言弹层 | 普通按钮堆叠，选中项用文字勾号；选完自动消失 | 当前语言说明、跟随系统副标题、浅橙选中行、独立勾号、关闭与完成；切换后保留弹层 |
| 关于 BitTap | 公开信息没有提示卡；入口图标不符；多出技术格式页脚 | 恢复盾牌提示卡、原型按钮、语言入口和关闭按钮；移除技术格式页脚 |
| 私钥如何生成与加密 | 普通链接代替折叠行；开源钱包比较直接铺开；缺少完整结尾与正确返回 | 独立页面、九组折叠、首组默认展开、箭头状态、分隔线、重点文字、清理提示、比较说明；顶部和底部均返回原来的关于弹窗 |
| 制作页准备卡片 | 普通正文和独立链接 | NFC 图标、浅橙提示卡、卡内行内链接与箭头 |
| 钱包备注输入 | 缺少「选填」与实时计数 | 标题右侧计数、示例、公开信息提示；按 Unicode 字符计数 |
| 相机增强设置 | 裸开关和分散说明 | 白色描边模式卡、相机图标、原型开关、两层说明、行内原理入口 |
| 密码区域 | 强度提示顺序不同；额外进度条；密码提示没有卡片 | 两个密码框后显示强度提示、移除额外强度条、恢复钥匙图标提示卡与生成按钮顺序 |
| 增强原理 | 三段普通文字 | 三个对应图标步骤、浅橙注意事项、统一确认按钮 |
| 相机采集 | 普通预览框与框外计数 | 圆角取景区、取景边框、预览计数、隐私提示、采集与取消按钮顺序 |
| 相机确认 | 小弹窗且没有照片与统计 | 独立确认页，显示实际匹配的最终照片、32 帧与 1 张照片统计、使用与重采集；确认、退出或后台时清理照片内存 |
| 写卡与完成 | 只读开关、备注核验信息和进度未按原型分组 | 模式卡、不可逆风险提示、备注左右标题与状态、三步进度、完成页状态与按钮层级 |
| 读取与解密 | 使用上一版标题和说明 | 使用新原型文案与顺序；保留旧格式和 BIP38 所需的真实兼容提示 |
| 其他地址与二维码 | 附加旧说明与文字箭头，二维码尺寸及风险样式不同 | 四地址行、真实下拉图标、完整地址、原型 QR 尺寸、风险提示卡、复制 / 保存、外部查询入口 |
| 浏览器选择 | 普通按钮且返回路径不符 | 地址卡、隐私卡、带域名的站点行、外链图标；返回原地址二维码 |
| NFC / 帮助弹层 | 关闭按钮、图标分组、扫描圈比例和分隔线不统一 | 统一弹层标题、关闭、图标与信息层级；处理中的 NFC 不能通过关闭或系统返回打断 |
| 只读异常 | 仅错误文字，缺少原型弹层 | 不支持时返回写卡设置；锁定未确认时明确提示并进入备份，保持「未知」状态 |

原型里的模拟画面、假扫码、模拟写卡与演示成功，不进入正式应用。真实相机、权限、读写、文件结果仍决定流程。安全说明中的「下一版方案」按实际实现状态调整，但保留原来的内容结构。

本轮没有改变私钥生成、scrypt、AES-GCM、CG3 字节格式、地址推导或永久锁定位算法。相机只新增内存照片预览；哈希与密钥混合仍使用原来的最终帧数据。照片不写文件，不参与 Android 页面序列化，使用后和生命周期退出时清理。

原型是网页，实际产品是 Android 原生界面；系统状态栏、导航栏、系统权限 / 文件选择器、字体渲染及字体放大随手机变化。内容超出屏幕时可滚动，不隐藏操作按钮。

验证记录及实际截图见 `docs/release/bittap-code8/`。实体 NFC 锁卡与真实手机相机兼容性仍须实机验收，界面对齐不代表硬件测试或独立资金安全审计通过。
