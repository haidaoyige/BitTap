# BitTap v0.6.2

Android 9+，版本 0.6.2 / 内部版本 31。应用 ID 与原发行证书保持一致，可覆盖同签名旧版。仓库保持私有，继续使用 Apache License 2.0。

## 本次更新

- 新建密码限定为可见 ASCII U+0021–U+007E：大小写英文字母、数字和半角标点，至少 10 位、最多 1024 位，且四类均包含。拒绝中文、emoji、全角字符、空格和隐藏字符，并明确提示；输入、粘贴及键盘提交使用一致校验，不静默删改密码。
- 长度校验与强度评估采用与 KDF 相同的 NFC 规范化表示；不修改加密格式或参数，不增加旧卡片兼容分支。恢复不套用新建密码门槛。
- 增加 32 位本机随机密码：系统 SecureRandom 从 94 个可见 ASCII 字符均匀采样，缺少必需类别时整串重新生成，随机源异常时停止。完整软换行显示，不向密码插入换行。
- 随机生成后再次输入保持为空，确认一致且勾选已安全保存后才能继续。重新生成需确认，清空旧确认输入与保存勾选；手动修改退出随机生成状态。中英日韩同步提示密码丢失无法找回、需与卡片分开保管。
- 随机密码复制带敏感标记并核对读回结果；Android 9 停用复制。自有剪贴板期限为 120 秒，并沿用前台重试与所有权检查；取消、重新生成及完成时尝试清理。密码弹窗不持久化输入或保存勾选。
- 风险弹窗缩为三项，移除“卡片可复制”整项；标题与盾牌并排，正文和间距加大，间距按可用高度调整。中英日韩同步，默认字号测试屏幕下无需滑动即可阅读并选择两个按钮。每次制作或读取均重新询问，完整条款与其入口保留。

## 验证

新增功能的本地核心、App 与恢复工具共 99 项单元测试通过；lint 无错误，保留 9 项既有警告。API35 签名 Release 构建上的四语言制作密码交互 385 项断言通过；API28 的同源码 Debug 检查 377 项断言通过，覆盖禁止复制及手动确认。四语言风险弹窗和每次入口同意流程 328 项断言通过，屏幕为 1080×1920、420 dpi、默认字体。历史功能测试与本次最终版本候选检查分别记录，不把旧 APK 的结果写成新 APK 的实测。

最终源提交必须通过独立 GitHub Actions CI，再由本机使用原证书签名，对比 CI 的 APK 非签名内容及离线恢复 ZIP，签发来源清单。最终提交、CI 链接、实际候选验证及附件摘要以 Release 的签名清单和验证附件为准。发行凭据和 instrumentation APK 不上传。

## 边界

格式合格不证明密码不可猜测，随机密码不能丢失。显式复制会产生不可保证清除的系统或外部副本；App 不代为保存或找回密码。极大辅助字体或极小窗口仍保留受保护滚动作为兜底，避免文字与同意按钮被截断。完整条款未改动。

保留 v0.6.1 的审计边界，包括“仅核验地址”独立操作尚未实施、解密期间私钥存在于内存、无法抵御 Root 或高权限恶意软件、BIP38 特殊标量兼容问题，以及个人私有仓库主分支强制保护的套餐限制。没有新增实体 NFC、相机熵认证、独立资金安全审计或真实资金转出验证。测试通过不等于资金安全保证。

## 安装

`BitTap-0.6.2.apk` 为主应用；`BitTap-0.6.2-offline-recovery.zip` 为 Java 17 离线恢复工具。随附 SHA-256、签名证书、SBOM、运行时库存与签名来源清单。
