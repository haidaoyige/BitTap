# BitTap 0.4.0 · code 13

移除私钥恢复页面底部的“复制 WIF 私钥”按钮。私钥二维码弹窗保留复制入口，先展示用户确认的底部风险提示；中文、英文、日文、韩文跟随 App 语言。
