# BitTap 0.4.0 · code 12

WIF 私钥 PNG 采用用户确认的“风险提示优先”设计：BitTap Logo、BTC 主网、明文泄露风险、二维码、完整 WIF、尽快转移全部 BTC、停用所有旧地址以及不要分享 / 上传的提示。已删除“这不是加密备份”。

标题及全部提示跟随 App 当前有效语言（中文、英文、日文、韩文）；`YOUR KEYS. YOUR BITCOIN.` 复用不可翻译的固定英文资源。各段按实际语言测量后排版，完整 WIF 居中换行，不省略；二维码只编码原始 WIF，不包含说明文字。

仅在用户确认保存后生成私钥图片。图片在内存生成，编码后擦除并回收绘制位图；保存用 PNG 沿用取消 / 失败 / 超时 / 写入后读回核验与字节清理流程，不创建临时图片缓存。打开系统文件选择器并切后台时，仍清理解密私钥及页面二维码。用户明确选定保存的图片会保留在所选位置。此处的清理是应用可控缓冲区清理，并非保证 JVM 或操作系统所有内存副本均可物理擦除。
