# BitTap v0.6.1

Android 9+，版本 0.6.1 / 内部版本 29，沿用原发行证书和应用 ID，可覆盖同签名旧版。仓库保持私有，项目继续使用 Apache License 2.0，不切换 GPL。

## 本次更新

- 制作与读取每次打开“风险提示”：简化为四项风险、条件性责任说明、完整条款入口及同意／不同意按钮；同意仅对本次入口有效。
- 完整使用条款缩短为六节：工具范围、私钥与备份、损失风险、使用前核验、责任范围、开源许可。中英日韩完整同步，开源许可与同意提示分别表述。
- 私钥生成与加密说明支持四语言，涵盖相机增强、数据清理、会话期限和保护边界。
- 首页、读卡页、写卡页和 NFC 弹窗共用高清卡片 Logo；锁头外框按物理像素对齐，保留既有比例、位置和动画。
- 新建密码至少 10 个 Unicode 码点，同时包含英文大小写、数字及特殊字符；仍提醒格式合格但明显规律的弱密码，旧备份解密兼容。
- 解锁后空闲 60 秒或达到 120 秒上限时清理私钥，以较早者为准；恢复页不显示倒计时。后台、首页和敏感出口继续执行清理及期限检查。
- 密码生成、加密和解密使用原弹窗按钮内的灰色“正在处理”状态及旋转图标；自动锁定使用 App 风格提示。文件任务有 15 秒期限、取消及迟到结果失效保护；保存失败手动确认关闭。
- 私钥使用专用绘制，不放入普通 TextView 或辅助功能文字节点；Android 9 保留 WIF 剪贴板限制。
- 未核验地址导出图增加多语言风险提示；收款地址及 WIF 图片为透明圆角 PNG，英文页脚保留。
- 安全报告渠道更新为 ianzhangone@outlook.com；未验证邮箱实际收发能力。

## 发布验证

最终源提交需通过独立 GitHub Actions CI（单元测试、严格依赖校验、未签名构建、密码学／地址独立复核、许可证和运行时依赖扫描），发行密钥仅在本机使用。上传前对比 CI 与本机 APK 非签名内容及离线恢复 ZIP，核对原证书并签发来源清单。实际提交、CI 链接与附件摘要以已签名的 release-manifest.json 为准，设备验证记录随发布提供。

此前 code28 的 API28/35 辅助功能保护、界面像素对照、图片、保存及真实 60 秒空闲锁定均有本地记录；新条款已完成四语言原生页面及入口同意流程验证。历史验证与最终候选验证须区分，不将本地测试视为独立资金安全审计。

## 保留的边界

- 待核验公开地址仍可展示和导出；提示不能代替与私钥核对。“仅核验地址”的独立操作尚未实施。
- 私钥在解密运算期间存在于内存中。专用绘制与自动清理不保证所有系统副本均可消除，也不抵御 Root、注入、恶意高权限自动操作或明确复制／导出后的明文泄露。
- 密码格式不保证足够熵；NFC 可被复制并用于离线猜测密码。BIP38 特殊标量兼容问题仍保留。
- 个人私有仓库的主分支强制保护尚未启用；CI 和来源签名不能代替服务端权限保护。
- 实体 NFC、实机相机熵和其他钱包实际转出仍需单独验收。请勿向公开测试夹具地址存入资金。

## 安装

主应用：`BitTap-0.6.1.apk`。离线恢复工具：`BitTap-0.6.1-offline-recovery.zip`，需要 Java 17。测试 instrumentation APK 和发行凭据不随 Release 分发。
