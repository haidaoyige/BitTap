## 改动和检查

- 地址卡和其他地址列表统一为“展示地址”入口；二维码底部弹层中的完整地址居中，显示名称改为 SegWit、P2SH，地址构造与备份字段不变。主地址栏完整换行，不再强制单行缩字。
- 移除加密文本复制与粘贴界面和路由，仅保留 NFC 和文件导入；NDEF Text 记录兼容性保留。
- 地址和 WIF 复制均先写入本次唯一标签，再读回确认标签与文本一致。拒绝、读取不可用、旧数据、不同内容及额外条目不报告成功；不确定的私钥复制仍纳入本应用的剪贴板清理范围。
- 地址与私钥二维码支持显式 PNG 导出。私钥图片先确认明文风险；使用系统 ACTION_CREATE_DOCUMENT 指定文件，不新增存储权限，不自动写入相册、应用文件或缓存。
- PNG 编码的临时输出缓冲清零。独立的待导出字节数组仅在用户请求后生成，取消、完成、失败、超时（3 分钟）、Activity 销毁或返回首页时清理；不写入 savedInstanceState，也不通过 RetainedFlow 保留。进入文件选择器仍关闭屏幕二维码并锁定私钥。活动写入的字节数组由工作线程在 finally 中清零。
- PNG 保存须成功关闭文件并逐字节读回一致后才提示成功；不会把图片当作加密备份，不会改变必须保存加密备份的完成条件。失败时文件提供程序可能已留下不完整文件，界面仅提示未确认成功，不擅自删除用户选定的文件。
- 本轮未改动密码学算法、随机源、依赖版本或 CG2 格式。核心 51、二维码 4、图片 I/O 6 项单元测试通过。新增 I/O 测试覆盖关闭失败、读写拒绝、空流、内容不一致、截断和额外数据。
- 最终发行 APK 通过 162 项 API 35 ARM64 模拟器断言，含地址/私钥保存 PNG 精确解码、风险确认与取消、失败/超时清理、切后台、地址居中与按钮完整边界，以及此前的钱包/NFC 弹层/备份/多卡流程。文件选择器启动由测试拦截，测试将真实文件 URI 送入正常结果处理方法，另行模拟 Activity 离开和返回；没有自动操作系统选择器的全部 UI。
- 最终发行 APK 通过 15 项安全现象复现断言。复现结果明确：解密后私钥已在本进程内存，30 秒遮蔽不等于锁定；主动显示 WIF 后辅助功能仍可能读取。切后台关闭 Unlocked 并清零其持有的标量，默认 UI 与 savedInstanceState 不包含 WIF，不自动复制私钥。
- APK v2 签名验证通过；Manifest 无 debuggable/testOnly，只有 NFC 权限，备份和明文网络禁用。run-as 被拒绝；生产 DEX 不包含测试 Runner、测试密码或标量夹具标记。测试 APK 与设备公开测试截图已清理。
- Release lint 无问题，git diff --check 通过。对应源码快照包括未提交调整，单凭 Git HEAD 不能复原本 APK；签名私钥与本机凭据不进入源码包。

## 保留的限制

弱密码仍只提示，卡片与备份可被离线猜测。解密前地址仍标为待核验，不能把公开地址显示当作已与私钥核对。NFC 卡可被复制。

显式保存的私钥 PNG 是明文，拿到图片就可能控制 BTC。用户指定的文件提供程序、云同步、图库或系统产生的外部副本不由本应用控制；已导出的图片不会在返回首页时自动删除。JVM、库、键盘、剪贴板历史和系统残留也不能承诺取证级擦除。文件选择过程中旋转或进程回收会取消本应用内的待导出图片，需要重新解密并保存。

依赖沿用之前的评审结果，本轮没有重新查询漏洞公告或升级依赖。未验证实体 NFC 中断与克隆、用户手机厂商权限行为、恶意输入法/辅助功能、全堆取证或外部钱包实际花费；Taproot 单私钥导入兼容仍需单独验证。模拟器通过不能代替实机验收。
