# BitTap v0.6.0

Android 9+，版本 0.6.0 / 内部版本 23，沿用原发行证书；仓库保持私有。

## 本次变化

- 首页首屏分布、NFC 波纹图标、页面标题及地址栏按钮对齐。
- 制作和解锁密码移入底部弹窗，适配键盘；恢复主页面仅保留“查看私钥”按钮，WIF、二维码、复制、图片导出与转出帮助集中于私钥弹窗。
- 新建密码至少 10 个字符；弱密码需再次确认，旧短密码备份仍可解密。
- Android 9 禁用 WIF 剪贴板复制；拒绝遮挡点击，Android 12+ 请求隐藏第三方覆盖窗口，并提供对应保护提示。
- 保存未核验地址二维码图片前确认风险；用户同意后可下载，导出图片样式保持。
- 新版 Camera2 采集页：32 帧采集中拍照按钮为灰色且不可点击，采满后恢复；匹配的最终照片在摘要交付后立即清空，返回制作页后再设置密码。四语言同步。
- BTA-06～11 后台修订：运行时依赖更新、严格依赖校验、独立 CI／来源签名、CLI 限长与期限、完整许可证／SBOM、私有 Issue 报告渠道。

## 来源与验证

发布使用最终提交的独立 GitHub Actions CI，签名密钥仅在本机使用。上传前比较 CI 与本机 APK 所有非签名 ZIP 条目及离线恢复 ZIP 摘要，验证原证书并签发 release-manifest.json。具体提交、CI 链接和附件摘要以 Release 附件的已签名清单为准。

code21 已完成 core/app 单元测试、Android 9/15 的密码弹窗和弱密码回归、Android 15 完整流程及四语言布局回归；code22 完成相机按钮 16 项 Camera2 专项断言。v0.6.0 将再次对最终版本执行构建及设备回归，交付验证记录随附件提供。

## 尚存边界

- 解锁会话的 120 秒绝对上限／60 秒空闲自动锁定尚未实施。私钥弹窗 60 秒关闭并清理展示，不等于结束前台解锁会话。
- “仅核验地址”的独立操作入口和私钥展示的专门辅助功能语义防护尚未实施；地址核验仍需要在本机内存中短暂解密。
- 长度合格的弱密码仍可被离线猜测；普通 NFC 卡可被复制，公开备注和地址可读取。
- 当前个人私有仓库未启用主分支强制保护。来源签名和 CI 不能代替该服务端控制。
- 模拟器回归不代表实体 NFC、实机相机或外部钱包转出验收；本次发布不宣称已经完成独立资金安全复审。完整盘点见 ../../security/REMEDIATION-STATUS.md。

## 安装

使用 BitTap-0.6.0.apk 覆盖安装同签名旧版。解压 BitTap-0.6.0-offline-recovery.zip 后可用 Java 17 运行离线恢复 CLI。不要安装或分发 instrumentation 测试 APK。不要向公开测试夹具地址充值。
