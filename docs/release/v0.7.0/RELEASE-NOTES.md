# BitTap v0.7.0

Android12及以上，版本0.7.0／内部版本50。沿用 `io.coingift.android` 与原发行证书，可覆盖安装同签名版本。仓库改为公开，继续使用 Apache License 2.0。

## 更新

- 汇总0.6.2发布后的本地修订。首页卡片、锁头与按钮比例调整；制作页卡片支持提示改为紧凑形式；移除随机密码功能，保留手动输入、确认和严格ASCII密码规则。
- 最低支持Android12，移除Android9–11专用路径，保留较新Android版本仍需要的兼容分支。
- 本机公开地址核验记录：首次完整密码核验并推导地址，或完成制作、写后核对及必需备份后建立记录；相同完整负载再次读取可免密码核对公开地址。未知／变化数据不会继承旧核验结果，记录可管理和删除。记录不存密码、私钥或完整备份。
- 私钥恢复后封装进临时Android Keystore会话，查看时短暂解封；60秒空闲、120秒上限、后台和首页清理继续执行。敏感操作增加辅助功能服务门禁，包含对合法服务的限制。
- 新建与项目格式恢复统一 scrypt N=32768/r=8/p=3；明确拒绝此前p=1内部测试卡和文件，不提供兼容分支。修正BIP38边界标量导入，外部标准格式按其标准处理。
- NFC数据操作与服务启停使用有界后台控制，已有只读卡在连接前拒绝，超时、取消及迟到结果不能误报成功。固定诊断代码不包含异常原文或钱包内容。
- NTAG215/216永久只读改为专用芯片锁位，绕开通用Ndef.makeReadOnly，修正动态锁页保留字节写入并逐步读回。最终仍要求移开再贴回，核验完整内容、实际锁位与NDEF只读状态；只打开开关不等于锁定成功。
- 更新当前README、安全报告渠道和发布说明，保留原四语言及离线流程。

## 验证与来源

功能基线code49已通过137项单元测试；同签名包在Android12和15模拟器分别通过192项锁定诊断、62项NFC隔离与时限、46项完整钱包流程、41项只读卡／阻塞控制／取消断言。0.7.0更改版本号后再次执行最终构建与回归，实际结果以Release附带VALIDATION.json为准，不将历史APK结果当作新APK测试。

最终干净源提交须通过独立CI，再在本机重建并逐项比较APK非签名内容、恢复ZIP，使用原证书签发来源清单。正式附件不包含发行密钥、密码或instrumentation APK。最终提交、运行编号和文件摘要见签名release-manifest.json。

## 重要边界

- 小米15／Android16曾发生锁定阶段NFC-LOCK-L3-TIME，随后停止读卡NFC-D。专用锁定为针对性修复，仍缺修复后的实体手机验收；模拟器及页权限模型不替代真实射频测试。请先用无资金测试钱包与测试卡。
- code47曾记录Android15模拟器可见取消1秒计时不稳定；code49单轮回归通过，不足以宣布该计时边界已永久消失。
- 锁定不可撤销，失败可能部分完成；保护不防复制、替换卡片、回滚或伪造芯片。仅最终完整核验成功才显示永久只读。
- 免密码核验记录减少重复解密次数，不证明卡片身份或余额；首次核验和明确导出仍短暂处理明文私钥。Root、注入、已攻破系统及外部明文副本风险仍存在。
- 相机采集是补充混合输入，未取得量化熵或硬件随机认证。未完成独立资金安全审计或所有外部钱包的实际资金转出验收。
- 旧p=1内部测试备份不兼容；请勿把覆盖安装成功等同于这些旧钱包可恢复。
