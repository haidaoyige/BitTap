# BitTap 0.4.0 · code 14

恢复页私钥二维码使用与“展示地址”相同的图标，移除无引用的旧图标资源；“如何转出 BTC”按内容宽度排列，右边缘与上方展示地址对齐。“隐藏私钥，返回首页”改为橙色主按钮并保留原会话清理路径。

Android 11+ 明确由页面处理系统栏与键盘 Insets，以两者底部较大值预留空间。输入框获取焦点、键盘 Insets 更新或窗口高度改变后，按键盘上方实际可见区域滚动，使整框与光标保持可见。旧系统保留 manifest 的 adjustResize 及窗口缩放处理；密码仍禁用自动填充、页面状态保存及个性化输入学习。
